# DenpyoHub_Miya（制作伝票一覧集計システム）

## 1. アプリの概要と機能

DenpyoHub_Miya は、日々の業務で管理されている4種類の管理ファイル（日報ファイル、購入品、外注加工、受注表）および各案件の制作伝票フォルダ（指定フォルダ直下の .xls / .xlsx / .xlsm・サブフォルダは含みません）を読み込み、管理Noごとに制作伝票の一覧表を自動作成するパソコン用ソフトです。

主な機能は以下の通りです。

- 日報ファイル、購入品、外注加工、受注表の複数選択・統合に加え、「制作伝票フォルダ」も複数フォルダをまとめて選択でき、選択した各フォルダ直下にあるすべてのExcelファイル（.xls / .xlsx / .xlsm・サブフォルダは自動探索しません）を一括読み込みできます。
- 参照するすべてのファイルおよび制作伝票フォルダは、共有読み取り専用データとして参照され、他のユーザーがExcel等でファイルを開いている状態でも支障なく集計・更新できます（元のファイルやフォルダ内が変更・上書きされることは一切ありません。誤って参照元ファイルや制作伝票フォルダ内へ保存しようとした場合も自動的にブロックされます）。
- 各ファイルが所定のフォーマット（サンプルファイルの列構成やシート構成）と異なる場合は、集計時にエラー画面が表示され、どのファイルのどの部分が異なるのか（エラー原因・期待されるフォーマット・検出された内容）を一覧で分かりやすく確認・コピーできます。画面上の「エラー確認」ボタンからいつでも再確認できます。
- 集計した一覧は左右2つの画面に分かれて表示されます。
  - 左側：管理No、受注先、出荷先、プロジェクト名などの「その他見出し・受注基本情報」
  - 右側：日報・購入品・外注加工・制作伝票から算出したデータと各小計（初期状態では「小計1」「小計2」「小計1+小計2」「諸経費(8%)」「合計」「合計/数量」「調整額」「総請求金額」「総請求金額/数量」をスッキリ表示し、一覧上部の「▶ 小計1内訳を表示」「▶ 小計2内訳を表示」「全内訳を表示」「小計のみ表示」ボタンでいつでも内訳項目を開閉できます）
  「行リンク連動」により、縦スクロール・並び順・選択行のハイライトが左右で自動的に揃うため、横並びで見比べながら確認できます（横スクロールやセル選択・コピーは左右別々に操作でき、必要に応じて「行リンク連動」のチェックを外して完全に個別操作することも可能です）。
- 一覧の作業データは初期設定（デフォルト）で「金額(円)」として表示されます。金額表示中は見出しも自動で「作業費(円)」「移動費(円)」「修理改造費(円)」「設計費(関係)(円)」「その他作業費(円)」「作業費小計(円)」などに切り替わり、時間・工数表示との違いが一目で分かります。一覧上部の「一括表示」ボタン（金額(円) / 時間(分) / 時間(h) / 工数(8h)）をクリックすると、金額・時間・工数（1工数＝8時間）を一括で切り替えられます。起動時のデフォルト表示単位や各単価レート（初期設定：作業時間 62.5円/分、移動時間 50円/分、修理改造時間 70円/分、設計関係 62.5円/分、その他作業 62.5円/分）は設定からいつでも変更・保存できます。
- 作業コードの割り当て範囲も画面上の設定からいつでも自由に変更でき、次回起動時にも設定が保持されます。初期設定は以下の通りです。
  - 作業時間：20～49
  - 移動時間：90～99
  - 修理改造時間：50～69
  - 設計関係：1～19
  - その他作業：70～89
- 購入品ファイルと外注加工ファイルのQ列（金額 単価X必要数）から、管理Noごとの購入品費・外注加工費（機械工費）と購入品小計を自動計算します。
- 制作伝票フォルダ直下（サブフォルダ除く）の各Excelファイルからは、調整用(21行)、材料費１（型鋼）(28行)、材料費２（鉄板）(29行)、材料費３（コラム）(30行)、その他材料費(31行・32行・33行)、切断材料(34行)、材料費計(35行)、設計費(36行)、重機、運搬費(AA17)、車両、交通費(AA18)、出張費(AA19)、総請求金額(AA30)、数量(AD9)を自動抽出し、「小計1」「消耗品費(6%)」「管理費」「小計2」「小計1+小計2」「諸経費(8%)」「合計」「合計/数量」「調整額（総請求金額−合計）」「総請求金額/数量」も自動算出します。
- 集計結果の列順や表示・非表示を変更し、保存できます。
- Excelのような列見出しフィルター機能および全体検索機能により、半角・全角カタカナや英数字の違い、数値のカンマ有無を気にせず素早く検索・絞り込みできます。フィルター画面ではキーワード入力からの「検索結果で即適用」や複数キーワードの連続チェック選択、数値条件（0より大きい、範囲指定など）に対応しています。
- ショートカットキー（Ctrl+C 等）だけでなく、左右それぞれの一覧下部にある専用ボタン（「選択コピー」「見出し付コピー」「この列を全コピー」「全セル選択」「選択解除」）を使って、別のExcelへ簡単に貼り付け（Ctrl+V）できます。
- 集計した一覧表だけでなく、選択した管理Noの「内訳明細」（日報データ・購入品・外注加工・受注表詳細・制作伝票）も、ファイルを保存する手間なく「Excel新規ブックで開く」ボタンから印刷設定済みのExcel新規ブック（未保存ブック）として直接開けます。

## 2. 動作環境

- 対応OS：Windows 11（64ビット版）
- 特別なソフトや専門的な設定は不要で、ダウンロードしたファイル単体ですぐにお使いいただけます（「Excel新規ブックで開く」機能をご利用の際はMicrosoft Excelが必要です）。

## 3. インストール・実行方法

面倒なインストール作業は必要ありません。

1. 配布された「DenpyoHub_Miya.exe」を、デスクトップや任意のフォルダなど分かりやすい場所に保存します。
2. 「DenpyoHub_Miya.exe」をダブルクリックすると、画面が最大化された状態でアプリが起動します。

### 初回起動時に青い警告画面（WindowsによってPCが保護されました）が表示された場合

パソコンのセキュリティ機能（Windows Defender SmartScreen）により、初めてアプリを起動した際に「WindowsによってPCが保護されました」という青い画面が表示されることがあります。これは新しく作成されたアプリに対して自動的に表示される確認画面ですので、故障やウイルスではありません。以下の手順で安全に起動できます。

1. 画面内の「詳細情報」という文字をクリックします。
2. 画面の下部に新しく表示される「実行」ボタンをクリックします。
3. アプリが通常通り起動します（2回目以降はこの画面は表示されません）。

## 4. 基本的な使い方

### 手順1：参照ファイル・制作伝票フォルダを選択する

画面右上の「▼ ファイル設定を開く」ボタンをクリックすると「参照ファイル設定」エリアが開きます（通常は一覧を広く見せるため閉じており、ボタンを押したときだけ開きます）。以下の5種類を設定します。

- 日報ファイル（例：daily_report.csv）
- 購入品ファイル（例：購入品.xlsm）
- 外注加工ファイル（例：外注加工.xlsm）
- 受注表ファイル（例：受注票頚城.xlsm）
- 制作伝票フォルダ（複数フォルダ選択可・選択した各フォルダ直下の .xls / .xlsx / .xlsm ファイルをすべて自動読み込み ※サブフォルダは自動探索しません）

各行のボタンを使って柔軟に設定できます。

- 「選択(複数可)」ボタン：対象ファイル（複数選択可）や制作伝票フォルダ（複数フォルダのチェック選択・削除・検出Excel確認が可能）を選びます。
- 「追加」ボタン：今選んでいる一覧に、別のファイルや別フォルダを素早く追加します。
- 「一覧」ボタン：選択中のファイルや、制作伝票フォルダ直下で検出されたExcelファイルの一覧・更新日時を確認・編集できます。

ファイルやフォルダを設定すると、右側に最新の更新日時や件数が表示されます。設定が終わったら右上の「▲ ファイル設定を畳む」ボタンで閉じて一覧を広く表示できます。

### 手順2：集計を実行する（フォーマットチェック機能付き）

アプリ起動直後はファイルの自動読み込みを行いません（起動が速く安全です）。参照ファイル・制作伝票フォルダを設定した状態で「集計・一覧更新」ボタン（またはF5キー）をクリックすると、操作バーの下に進捗バー（進捗率・処理中ファイル名・「中止」ボタン付き）が表示され、主要4ファイル（日報・購入品・外注加工・受注表）と大量の制作伝票ファイルの両方を画面が固まることなく高速に並列読み込みします。未変更ファイルはキャッシュから即時復元されるため、2回目以降の更新はさらに短時間で完了します（制作伝票キャッシュはアプリと同じフォルダの denpyohub_seizo_cache.json に自動保存されます）。

万一、各ファイルの形式が所定のフォーマット（見出し列やシート名など）と異なる場合は、自動的に「エラー内容の確認」画面が開き、ファイルごとの原因・期待されるフォーマット・検出内容を確認できます。閉じた後も「エラー確認」ボタンからいつでも詳細を確認できます。

### 手順3：一括表示切替（金額／時間／工数）と単価レート・既定表示設定

1. 起動時はデフォルトで「金額(円)」表示になっており、右側の算出一覧の見出しも「作業費(円)」「移動費(円)」「修理改造費(円)」「設計費(関係)(円)」「その他作業費(円)」「作業費小計(円)」「購入品費(円)」「外注加工費(円)」「購入品小計(円)」「調整用(円)」「材料費１(型鋼)」「材料費２(鉄板)」「材料費３(コラム)」「その他材料費(31行)～(33行)」「切断材料(円)」「材料費計(円)」「設計費(円)」「小計1(円)」「消耗品費(6%)(円)」「重機、運搬費(円)」「車両、交通費(円)」「出張費(円)」「管理費(円)」「小計2(円)」「小計1+小計2(円)」「諸経費(8%)(円)」「合計(円)」「合計/数量(円)」「調整額(円)」「総請求金額(円)」「総請求金額/数量(円)」と分かりやすく表示されます。
2. 一覧上部の「一括表示」ボタンから、「金額(円)」「時間(分)」「時間(h)」「工数(8h)」のどれかをクリックすると、右側の算出一覧の見出し・数値・下部サマリーが一括で切り替わります（1工数＝8時間＝480分で自動換算されます）。
3. 起動時のデフォルト表示単位や、1分あたりの単価レートを変更したい場合は、上部の「表示・レート設定」（または「レート・既定設定」）ボタンをクリックして設定し、「保存して適用」を押します（初期単価：作業時間 62.5円/分、移動時間 50円/分、修理改造時間 70円/分、設計関係 62.5円/分、その他作業 62.5円/分）。

### 手順4：左右一覧の行リンク比較・小計1/2の内訳開閉・Excel風フィルター・全体検索

- 小計1・小計2の内訳表示切替：右側の算出一覧は、初期状態（デフォルト）では「小計1」「小計2」に対する内訳項目を隠して見やすく表示しています。一覧上部にある「▶ 小計1内訳を表示」「▶ 小計2内訳を表示」ボタン（および「全内訳を表示」「小計のみ表示」ボタン）をクリックすると、作業費・購入品・外注加工・材料費・消耗品費・重機運搬費・車両交通費・出張費・管理費などの内訳列をワンクリックで展開・折りたたみできます。

- 行リンク連動（デフォルトON）：左側の「その他見出し・受注基本情報」と右側の「算出データ・各小計」は行同士がリンクしており、縦スクロール・並び順・クリックした行の強調表示が左右で自動的に連動します。横スクロールは左右それぞれ独立して動かせるため、見たい見出しと算出金額を横並びで楽に比較できます。
- 個別モードへの切り替え：一覧上の「行リンク連動」のチェックを外すと、縦スクロールや並び替えも左右別々に動かせます。
- 横スクロール：各一覧上で Shiftキーを押しながらマウスホイールを回すと左右にスクロールします。
- 全体検索：一覧上部の「全体検索」欄にキーワードを入力して「検索」ボタン（またはEnterキー）を押すと、管理No・受注先・出荷先・品名・製品詳細などから一括で絞り込めます。半角・全角カタカナや英数字の違いを区別せず、スペース区切りでの複数キーワード検索にも対応しています。
- Excel風フィルター：各列の見出しの右端にある「▽」マークをクリック（または見出し上で右クリック）すると、絞り込みウィンドウが開きます。
  - 「検索」欄に文字や数値を入力すると、候補リストがリアルタイムに絞り込まれます（半角・全角の違いや、4375と4,375のようなカンマの有無も自動で吸収します。日本語入力のEnter確定で勝手に画面が閉じない安全設計です）。
  - 検索欄の横にある「検索結果で即適用」ボタンを押すと、検索にヒットした項目だけで即座に一覧を絞り込めます。
  - 「全解除」を押してから複数のキーワードを順番に検索し、必要な項目にチェックを足していく操作や、「表示中のみ選択」「全選択」ボタンを使った一括チェック、マウスドラッグでの連続チェック切り替えも可能です。
  - 数値の列では「0より大きい (>0)」「以上 (>=)」「範囲」などの数値条件も指定でき、下部の「OK（適用）」ボタンで確実に反映されます。
  - すべての列フィルターを一度に戻したいときは、「全列フィルター解除」ボタンをクリックします。
- 内訳明細の確認・コピー・Excel出力：左右どちらの一覧でもセルや行をクリックすると、その管理No行が左右とも青く強調され、画面下部の5つのタブ（日報データ明細・購入品明細・外注加工明細・受注表詳細情報・制作伝票明細）に内訳と各件数・合計（時間・工数・金額）が表示されます。明細タブ内でも行を選択して Ctrl+C または右クリックメニューからコピーでき、上部の「表示中タブをExcelで開く」「内訳明細をExcelで開く（全タブ）」ボタンから印刷設定済みのExcel新規ブックとしてそのまま開けます。

### 手順5：ボタンやショートカットでセル・範囲・列をコピーしてExcelに貼り付ける

ショートカットキー（Ctrl+C など）だけでなく、左右それぞれの一覧下部にある専用ボタンからも簡単にコピーして別のExcelへ貼り付け（Ctrl+V）できます。選択中は青い枠線が表示され、一覧の下部に選択セル数・数値合計・平均値が表示されます。

- 選択してからボタンでコピー：
  1. コピーしたいセルをクリック（範囲を選ぶ場合はドラッグまたは Shift+クリック、離れたセルは Ctrl+クリック）します。
  2. 一覧下の「選択コピー」ボタン（または見出しを1行目に付けたい場合は「見出し付コピー」ボタン）をクリックします。
- 選択中の列を1列まるごとコピー：
  コピーしたい列のいずれかのセルをクリックした状態で、一覧下の「この列を全コピー」ボタンをクリックすると、その列の全データがコピーされます（Ctrlキーを押しながら列見出しをクリック、または見出し右クリックでも列まるごと選択・コピーできます）。
- 表全体をコピー／選択を解除：
  一覧下の「全セル選択」ボタンで表全体を選択でき、「選択解除」ボタンで選択をクリアできます。
- ショートカットキー・メニュー操作：
  Ctrl+C（選択範囲をコピー）、Ctrl+Shift+C（見出し付きでコピー）、Ctrl+A（表示中の全セルを選択）、右クリックメニューでのコピーもそのまま使えます。
- 左右をまたいで複数列をまとめてコピー：
  画面上部の「列を選んでコピー」ボタンをクリックし、コピーしたい列にチェックを入れてコピーできます（「その他見出しのみ」「集計・小計のみ」などの一括選択ボタンもあります）。

### 手順6：列の順番や表示を変更する

1. 画面上部の「列の順番・表示」ボタン（または列見出しを右クリックして「列の順番・表示設定...」）をクリックします。
2. 列を選んで「上へ」「下へ」ボタンで好きな順番に並べ替えたり、ダブルクリックで表示・非表示を切り替えたりできます。
3. 「保存して適用」をクリックすると一覧表に反映され、順番の設定が保存されます。

### 手順7：作業コードの範囲を変更する

1. 画面上部の「作業コード設定」ボタンをクリックします。
2. 作業時間、移動時間、修理改造時間、設計関係、その他作業のそれぞれについて、集計したいコードの範囲（例：20-49）を入力します。
3. 「保存して再算出」ボタンをクリックすると、新しい設定で即座に再計算されます。

### 手順8：設定の保存と読み込み（デフォルト：アプリと同じ場所）

選択したファイル・フォルダ一覧、作業コード設定、単価レート設定、起動時のデフォルト表示単位、行リンク連動設定、列の順番、列幅、画面分割位置、表示設定などは、自動的にアプリと同じフォルダの「denpyohub_config.json」に安全に保存され、次回起動時に自動で復元されます。
「設定保存 / 読込」ボタンから、明示的に設定を保存したり、別のフォルダに設定ファイルを保存・読み込みしたり、設定を初期状態に戻したりすることもできます。

### 手順9：集計一覧・内訳明細をExcelの新規ブックとして開く（印刷レイアウト・列グループ化対応）

1. 集計一覧全体をExcelで開く場合：一覧上部の緑色の「Excel新規ブックで開く」ボタンをクリックします。
2. ファイル保存ダイアログを出さずに、現在画面に表示されている表示単位（金額・時間・工数）・フィルター結果・列の順番のまま、A3横向き（A3非対応プリンタ環境ではA4横へ自動切替）・全列1ページ収め・見出し行の毎ページ繰り返し・タイトル/出力日時/ページ番号付き・合計行・オートフィルタ設定済みの新しいExcelブック（未保存ブック）が印刷レイアウト表示（ページレイアウトビュー）で開きます。
3. 小計1・小計2に対する内訳列はExcelの列グループ化機能でデフォルト折りたたみ（非表示）された状態で開きます。Excel上部の「+」「-」ボタンでいつでも内訳を展開・折りたたみでき、印刷時もグループの表示・非表示状態に自動で適応して1ページ幅に収まるように印刷されます。
4. 選択した管理Noの内訳明細をExcelで開く場合：一覧から確認したい管理Noをクリックし、下部「選択した管理Noの内訳明細」の「表示中タブをExcelで開く」（現在開いている1タブのみ）または「内訳明細をExcelで開く（全タブ）」（日報・購入品・外注加工・受注表詳細・制作伝票の全5シート）をクリックします。管理No・受注先・出荷先・品名入りのタイトル、合計行、長文の自動折り返し、A4横向き・横1ページ収め・タイトル/見出し行の毎ページ繰り返し・ページ番号付きの印刷レイアウト表示でExcel新規ブックが開きます。
