# DenpyoHub_Miya（制作伝票一覧集計システム）

## 1. アプリの概要と機能

DenpyoHub_Miya は、日々の業務で管理されている4種類のファイル（日報ファイル、購入品、外注加工、受注表）を読み込み、管理Noごとに制作伝票の一覧表を自動作成するパソコン用ソフトです。

主な機能は以下の通りです。

- 4種類の参照ファイル（日報ファイル、購入品、外注加工、受注表）をそれぞれ複数選択して合算・統合できます。各ファイルの最終更新日時も画面上で確認できます。なお、参照ファイルは読み取り専用で開き、元のファイルが変更・上書きされることはありません。
- 集計した一覧は左右2つの画面に分かれて表示されます。
  - 左側：管理No、受注先、出荷先、プロジェクト名などの「その他見出し・受注基本情報」
  - 右側：日報・購入品・外注加工から算出したデータと各小計（「作業時間、移動時間、修理改造時間、設計関係、その他作業、作業小計、購入品、外注加工、購入品小計」）
  「行リンク連動」により、縦スクロール・並び順・選択行のハイライトが左右で自動的に揃うため、横並びで見比べながら確認できます（横スクロールやセル選択・コピーは左右別々に操作でき、必要に応じて「行リンク連動」のチェックを外して完全に個別操作することも可能です）。
- 一覧の作業データは初期設定（デフォルト）で「金額(円)」として表示されます。金額表示中は見出しも自動で「作業費(円)」「移動費(円)」「修理改造費(円)」「設計費(円)」「その他作業費(円)」「作業費小計(円)」などに切り替わり、時間表示との違いが一目で分かります。一覧上部の「一括表示」ボタン（金額(円) / 時間(分) / 時間(h)）をクリックすると、時間と金額を一括で切り替えられます。起動時のデフォルト表示単位や各単価レート（初期設定：作業時間 62.5円/分、移動時間 50円/分、修理改造時間 70円/分、設計関係 62.5円/分、その他作業 62.5円/分）は設定からいつでも変更・保存できます。
- 作業コードの割り当て範囲も画面上の設定からいつでも自由に変更でき、次回起動時にも設定が保持されます。初期設定は以下の通りです。
  - 作業時間：20～49
  - 移動時間：90～99
  - 修理改造時間：50～69
  - 設計関係：1～19
  - その他作業：70～89
- 購入品ファイルと外注加工ファイルのQ列（金額 単価X必要数）から、管理Noごとの購入品費・外注加工費（機械工費）と購入品小計を自動計算します。
- 集計結果の列順や表示・非表示を変更し、保存できます。
- Excelのような列見出しフィルター機能により、値ごとのチェックボックス選択や数値条件（0より大きい、範囲指定など）で素早く絞り込めます。
- ショートカットキー（Ctrl+C 等）だけでなく、左右それぞれの一覧下部にある専用ボタン（「選択コピー」「見出し付コピー」「この列を全コピー」「全セル選択」）を使って、別のExcelへ簡単に貼り付け（Ctrl+V）できます。
- 集計した一覧表は、ファイルを保存する手間なく「Excel新規ブックで開く」ボタン1つでExcelの新規ブック（未保存ブック）として直接開けます。

## 2. 動作環境

- 対応OS：Windows 11（64ビット版）
- 特別なソフトや専門的な設定は不要で、ダウンロードしたファイル単体ですぐにお使いいただけます（「Excel新規ブックで開く」機能をご利用の際はMicrosoft Excelが必要です）。

## 3. インストール・実行方法

面倒なインストール作業は必要ありません。

1. 配布された「DenpyoHub_Miya.exe」を、デスクトップや任意のフォルダなど分かりやすい場所に保存します。
2. 「DenpyoHub_Miya.exe」をダブルクリックすると、画面が最大化された状態でアプリが起動します。

### 初回起動時に青い警告画面（WindowsによってPCが保護されました）が表示された場合

パソコンのセキュリティ機能（Windows Defender SmartScreen）により、初めてアプリを起動した際に「WindowsによってPCが保護されました」という青い画面が表示されることがあります。これは新しく作成されたアプリに対して自動的に表示される確認画面ですので、故障やウイルスではありません。以下の手順で安全に起動できます。

1. 画面内の「詳細情報」という文字をクリックします。
2. 画面の下部に新しく表示される「実行」ボタンをクリックします。
3. アプリが通常通り起動します（2回目以降はこの画面は表示されません）。

## 4. 基本的な使い方

### 手順1：参照ファイルを選択する（複数選択に対応）

画面上部の「参照ファイル設定」エリアから、以下の4種類のファイルを選択します。

- 日報ファイル（例：daily_report.csv）
- 購入品ファイル（例：購入品.xlsm）
- 外注加工ファイル（例：外注加工.xlsm）
- 受注表ファイル（例：受注票頚城.xlsm）

各行のボタンを使って柔軟にファイルを設定できます。

- 「選択(複数可)...」ボタン：ファイルを1つまたは複数同時に選び直します（CtrlキーやShiftキーを押しながら複数選択できます）。
- 「追加...」ボタン：今選んでいるファイルに、別の月や別フォルダのファイルを追加します。
- 「一覧...」ボタン：現在選択中のファイル一覧とそれぞれの更新日時を確認したり、不要なファイルを1件ずつ削除したりできます。
- 「フォルダから4ファイルを一括自動選択...」ボタン：同じフォルダにファイルが入っている場合、フォルダを選ぶだけで4種類の対象ファイルをすべて自動登録します。

ファイルを設定すると、右側に更新日時（複数選択時は最新の更新日時と件数）が表示されます。画面を広く使いたいときは、右上の「▲ ファイル設定を畳む」ボタンで折りたたむこともできます。

### 手順2：集計を実行する

アプリ起動直後はファイルの自動読み込みを行いません（起動が速く安全です）。参照ファイルが選択された状態で「集計・一覧更新」ボタンをクリックすると、すべてのファイルが読み込まれ、画面中央の左右一覧に制作伝票データが表示されます。

### 手順3：一括表示切替（金額／時間）と単価レート・既定表示設定

1. 起動時はデフォルトで「金額(円)」表示になっており、右側の算出一覧の見出しも「作業費(円)」「移動費(円)」「修理改造費(円)」「設計費(円)」「その他作業費(円)」「作業費小計(円)」「購入品費(円)」「外注加工費(円)」「購入品小計(円)」と分かりやすく表示されます。
2. 一覧上部の「一括表示」ボタンから、「金額(円)」「時間(分)」「時間(h)」のどれかをクリックすると、右側の算出一覧の見出し・数値・下部サマリーが一括で切り替わります。
3. 起動時のデフォルト表示単位や、1分あたりの単価レートを変更したい場合は、上部の「表示・レート設定...」（または「レート・既定設定...」）ボタンをクリックして設定し、「保存して適用」を押します（初期単価：作業時間 62.5円/分、移動時間 50円/分、修理改造時間 70円/分、設計関係 62.5円/分、その他作業 62.5円/分）。

### 手順4：左右一覧の行リンク比較・個別操作とExcel風フィルター

- 行リンク連動（デフォルトON）：左側の「その他見出し・受注基本情報」と右側の「算出データ・各小計」は行同士がリンクしており、縦スクロール・並び順・クリックした行の強調表示が左右で自動的に連動します。横スクロールは左右それぞれ独立して動かせるため、見たい見出しと算出金額を横並びで楽に比較できます。
- 個別モードへの切り替え：一覧上の「行リンク連動」のチェックを外すと、縦スクロールや並び替えも左右別々に動かせます。
- 横スクロール：各一覧上で Shiftキーを押しながらマウスホイールを回すと左右にスクロールします。
- Excel風フィルター：各列の見出しの右端にある「▽」マークをクリック（または見出し上で右クリック）すると、絞り込みウィンドウが開きます。
  - チェックボックスで表示したい値を選んだり、文字を入力して候補を絞り込めます。
  - 数値の列では「0より大きい (>0)」「以上 (>=)」「範囲」などの数値条件も指定できます。
  - すべての列フィルターを一度に戻したいときは、「全列フィルター解除」ボタンをクリックします。
- 内訳明細の確認：左右どちらの一覧でもセルや行をクリックすると、その管理No行が左右とも青く強調され、画面下部のタブに日報明細（時間および金額を含む）、購入品明細、外注加工明細、受注表詳細が表示されます。

### 手順5：ボタンやショートカットでセル・範囲・列をコピーしてExcelに貼り付ける

ショートカットキー（Ctrl+C など）だけでなく、左右それぞれの一覧下部にある専用ボタンからも簡単にコピーして別のExcelへ貼り付け（Ctrl+V）できます。選択中は青い枠線が表示され、一覧の下部に選択セル数・数値合計・平均値が表示されます。

- 選択してからボタンでコピー：
  1. コピーしたいセルをクリック（範囲を選ぶ場合はドラッグまたは Shift+クリック、離れたセルは Ctrl+クリック）します。
  2. 一覧下の「選択コピー」ボタン（または見出しを1行目に付けたい場合は「見出し付コピー」ボタン）をクリックします。
- 選択中の列を1列まるごとコピー：
  コピーしたい列のいずれかのセルをクリックした状態で、一覧下の「この列を全コピー」ボタンをクリックすると、その列の全データがコピーされます（Ctrlキーを押しながら列見出しをクリック、または見出し右クリックでも列まるごと選択・コピーできます）。
- 表全体をコピー：
  一覧下の「全セル選択」ボタンをクリックしてから「選択コピー」または「見出し付コピー」ボタンをクリックします。
- ショートカットキー・メニュー操作：
  Ctrl+C（選択範囲をコピー）、Ctrl+Shift+C（見出し付きでコピー）、Ctrl+A（表示中の全セルを選択）、右クリックメニューでのコピーもそのまま使えます。
- 左右をまたいで複数列をまとめてコピー：
  画面上部の「列を選んでコピー...」ボタンをクリックし、コピーしたい列にチェックを入れてコピーできます（「その他見出しのみ」「集計・小計のみ」などの一括選択ボタンもあります）。

### 手順6：列の順番や表示を変更する

1. 画面上部の「列の順番・表示...」ボタン（または列見出しを右クリックして「列の順番・表示設定...」）をクリックします。
2. 列を選んで「上へ」「下へ」ボタンで好きな順番に並べ替えたり、ダブルクリックで表示・非表示を切り替えたりできます。
3. 「保存して適用」をクリックすると一覧表に反映され、順番の設定が保存されます。

### 手順7：作業コードの範囲を変更する

1. 画面上部の「作業コード設定...」ボタンをクリックします。
2. 作業時間、移動時間、修理改造時間、設計関係、その他作業のそれぞれについて、集計したいコードの範囲（例：20-49）を入力します。
3. 「保存して再算出」ボタンをクリックすると、新しい設定で即座に再計算されます。

### 手順8：設定の保存と読み込み（デフォルト：アプリと同じ場所）

選択したファイル一覧、作業コード設定、単価レート設定、起動時のデフォルト表示単位、行リンク連動設定、列の順番、列幅、表示設定などは、自動的にアプリと同じフォルダの「denpyohub_config.json」に保存され、次回起動時に自動で復元されます。
「設定保存 / 読込...」ボタンから、明示的に設定を保存したり、別のフォルダに設定ファイルを保存・読み込みしたりすることもできます。

### 手順9：集計結果をExcelの新規ブックとして開く

1. 一覧上部の緑色の「Excel新規ブックで開く」ボタンをクリックします。
2. ファイル保存ダイアログを出さずに、現在画面に表示されている表示単位（金額・時間）・フィルター結果・列の順番のまま、合計行・オートフィルタ・書式設定済みの新しいExcelブック（未保存ブック）が開きます。そのまま必要な編集や名前を付けて保存を行えます。
